# 装配、供电与校准

[English](assembly.md) · **简体中文** · [日本語](assembly.ja.md)

打印件到手后约 15 分钟。没有胶粘结构件，壳体之间没有一颗螺丝。

## 什么固定什么

| 接口 | 方式 |
|---|---|
| 主箱 | 一体打印件——无需组装 |
| 顶盖 → 主箱 | 裙边盖，直接扣上。10 mm 裙边负责定位兼遮光，无螺丝 |
| 胶片台 → 顶盖 | 三根 M6×35 螺杆旋入热熔铜螺母，台面被上下螺母夹住 |
| 扩散板 → 台面 | 平放在开口上，靠胶片夹自重压平 |
| 胶片夹 → 台面 | 四个定位挡块管 X/Y，四颗磁铁吸铁垫片 |
| 抽口盖板 → 主箱 | 塞边缠 EVA 海绵条，摩擦配合 |

## 步骤

1. **热压铜螺母。** 用烙铁把三颗 M6 铜螺母压入顶盖下方的螺柱，冷却后再受力。
2. **喷外面。** 遮蔽内腔和开口，把主箱外表面和顶盖上表面喷哑光黑。内部保持白色耗材原样。
3. **扣顶盖。** 想要更严的遮光可先在墙顶边贴一圈 EVA 条。
4. **装台面。** 三根 M6×35 旋入铜螺母；每根先拧上一颗下螺母，台面经 Ø6.5 光孔落上，再上上螺母。三颗下螺母先拧到相同圈数，然后对着相机调平（胶片面放镜子法）：前螺母调俯仰、后侧一对调滚转，两轮收敛后锁紧上螺母。三点支撑是有意为之——原理见[设计文档](design.zh-CN.md)。
5. **台面附件。** 定位挡块已是打印台的一部分，只需把四片铁垫片粘到台面。（原型捷径：不竖用的话，垫片和夹子磁铁都可以省。用铝台时另需粘上打印挡块。）
6. **扩散板与夹子。** 亚克力盖住台面开口，胶片夹放上去、落在挡块之间。
7. **光源。** 闪光灯平躺箱底，灯头掰 90° 朝远端白壁，接收器接在灯脚上。**灯身上表面贴一张白纸**——黑色灯身正处开口正下方，不贴会拍出暗斑。LED 灯带贴在侧壁约 50 mm 高处，线经 Ø12 过线圈引出。
8. **封口。** 盖板塞边缠一圈 EVA 后插入抽口。

校准完成后，在箱底沿灯身画一圈定位线，以后放回同一位置。

## 供电

箱体内不进任何市电。

| 设备 | 供电 |
|---|---|
| TT560 | 4 × AA，无外接口。两组镍氢电池轮换最实用 |
| ZENIKO T1 | 自带电池（USB-C 或纽扣，视实物而定） |
| LED 灯带 | USB 5 V 充电宝或充电头，线控调光器在箱外 |
| 相机 | 电池；长时间批量扫描值得配假电池 |

桌上一个双口 USB 充电头就能覆盖灯带与引闪器。

## 校准

1. 夹内不装胶片，按实拍光圈拍摄发光面（RAW）。
2. 先在后期做 flat-field 校正——把镜头暗角与光源不均分离。光源本身的目标是**四角差约 ±0.1 EV**。
3. 达不到时按此顺序调整：
   - 闪光灯居中，检查灯身白纸。
   - 远端比近端亮时，在远壁临时立一张白卡并调整角度。
   - 最后手段：在扩散板下表面中心贴一小片半透明减光点。
4. 满意后在箱底装两个定位销，记录各画幅的立柱高度。

闪光曝光能冻结残余振动，但治不了胶片面与传感器不平行。平行度依然是第一优先——先用三颗螺母调平台面，再用胶片面放小镜子的方法对齐相机，最后才轮到匀场。

## 竖用（箱体立起）

设计支持把箱体立起来使用：

- **胶片夹**——底面四颗磁铁吸铁垫片＋挡块承重，任何朝向不脱落。*原型没装磁铁的话，不要竖用。*
- **胶片台**——螺杆入铜螺母＋双螺母夹持，任何朝向刚性。
- **抽口盖板**——贴一条胶带防脱出，灯旁空隙塞一块泡棉防移位。
- **扩散板**——被夹子压住即可。

## 每次开工

先气吹亚克力两面和片窗。胶片离扩散板只有约 4 mm，那里的灰尘会成为直径约 0.2 mm 的柔斑——反转负片上无害，正片上可见。
