# 組立・電源・キャリブレーション

[English](assembly.md) · [简体中文](assembly.zh-CN.md) · **日本語**

パーツが揃えば約 15 分。構造用の接着はなく、筐体同士を留めるネジも 1 本もありません。

## 何が何を固定するか

| インターフェース | 方式 |
|---|---|
| 本体 | 一体プリント——組み立て不要 |
| 天板 → 本体 | スカート付きの蓋を被せるだけ。10 mm スカートが位置決め兼遮光。ネジなし |
| ステージ → 天板 | M6×35 寸切り 3 本をインサートへ、ステージは上下ナットで挟持 |
| 拡散板 → ステージ | 開口の上に置くだけ。ホルダーの自重で平らに保持 |
| ホルダー → ステージ | 位置決めブロック 4 個が X/Y、マグネット 4 個が鉄ワッシャーに吸着 |
| アクセスパネル → 本体 | プラグに EVA フォームを巻いて摩擦嵌合 |

## 手順

1. **インサートを熱圧入。** はんだごてで M6 インサートナット 3 個を天板下面のポストに圧入し、冷えてから負荷をかけます。
2. **外側を塗装。** 内腔と開口をマスキングし、本体外面と天板上面をつや消し黒でスプレー。内側は白フィラメントの生地のまま。
3. **天板を被せる。** より厳密な遮光が欲しければ、壁の上縁に EVA テープを一周貼ってから。
4. **ステージを組む。** 寸切り 3 本をインサートへねじ込み、各々に下ナットを通し、ステージを Ø6.5 バカ穴で落とし込み、上ナットを掛けます。まず下ナット 3 個を同じ回転数に揃え、カメラに対して水平出し（フィルム面に鏡を置く方式）：前ナットがピッチ、後方ペアがロール。2 巡で収束したら上ナットで固定。3 点支持は意図的な設計です——理由は[設計ドキュメント](design.ja.md)へ。
5. **ステージまわり。** 位置決めブロックはプリント版ステージに一体化済み。鉄ワッシャー 4 枚を上面に接着するだけです。（プロトタイプの近道：立てて使わないならワッシャーもホルダーのマグネットも省略可。アルミステージの場合はプリントブロックの接着も必要。）
6. **拡散板とホルダー。** アクリルをステージ開口に被せ、その上にホルダーをブロックの内側へ置きます。
7. **光源。** ストロボを箱底に寝かせ、発光部を 90° 回して奥の白壁へ向け、レシーバーは脚に装着。**本体上面に白い紙を貼ります**——黒いボディが開口の真下にあり、貼らないと暗い染みとして写り込みます。LED ストリップを側壁の高さ約 50 mm に貼り、ケーブルを Ø12 グロメットから出します。
8. **閉める。** パネルのプラグに EVA を一周巻いて開口へ差し込みます。

キャリブレーション後、箱底のストロボの輪郭に線を引いておくと、いつでも同じ位置に戻せます。

## 電源

筐体内に商用電源は一切入れません。

| 機器 | 電源 |
|---|---|
| TT560 | 単3 × 4、外部電源端子なし。ニッケル水素 2 セットのローテーションが実用的 |
| ZENIKO T1 | 内蔵電池（個体により USB-C またはボタン電池） |
| LED ストリップ | USB 5 V（モバイルバッテリーか充電器）、インライン調光器は箱の外 |
| カメラ | バッテリー。長時間のスキャンにはダミーバッテリーが有効 |

机上に 2 口 USB 充電器が 1 つあれば LED とトリガーをまかなえます。

## キャリブレーション

1. フィルムを入れずに、実際に使う絞りで発光面を RAW 撮影します。
2. まずフラットフィールド補正を——レンズの周辺減光と光源のムラを分離するためです。光源自体の目標は**四隅差およそ ±0.1 EV**。
3. 届かない場合は次の順で：
   - ストロボをセンタリングし、本体上面の白紙を確認。
   - 奥側が明るいなら、奥の壁に白いカードを立てて角度を変えてみる。
   - 最終手段として、拡散板下面の中央に小さな半透明の減光ドットを貼る。
4. 決まったら箱底に位置決めピンを 2 本打ち、フォーマットごとのコラム高さを記録。

ストロボは残留振動によるブレを凍結しますが、フィルム面とセンサーの平行ずれは直せません。平行度が常に最優先です——3 個のナットでステージを水平にし、フィルム面に小さな鏡を置いてカメラを合わせてから、均一性の追い込みに移ってください。

## 縦置き使用

筐体を立てて使う場合：

- **ホルダー**——底面マグネット 4 個の吸着＋ブロックの支持で、どの向きでも脱落しません。*プロトタイプでマグネットを省いた場合は縦置き禁止。*
- **ステージ**——インサートへの締結＋ダブルナットで、どの向きでも剛。
- **アクセスパネル**——脱落防止にテープを 1 本、ストロボ脇の隙間にはスポンジを 1 個。
- **拡散板**——ホルダーが押さえています。

## 毎セッションの習慣

開始前にアクリル両面とフィルムゲートをブロワーで払うこと。フィルムは拡散板のわずか約 4 mm 上にあり、そこの塵は直径約 0.2 mm の淡い斑として写ります——反転ネガでは無害、ポジでは見えます。
