# NeoBox

[English](README.md) · **简体中文** · [日本語](README.ja.md)

用于翻拍扫描（相机扫描）135 与 120 胶片的紧凑型闪光光源箱，最大支持 6×9，全部零件可 3D 打印。

闪光灯完全平躺在箱底、**水平**射向全白内腔。光不会直接向上——它先在白壁之间漫反射数次，再穿过胶片夹正下方那块乳白亚克力到达胶片。由于混光距离走的是水平方向，箱体高度由闪光灯的**厚度**而非高度决定，这正是它能做到这么小的原因。

```
208 × 273 × 96 mm   ·   约 5.4 L   ·   8 个打印件 + 1 块亚克力 + 3 根螺杆
```

| | |
|---|---|
| **支持画幅** | 135、120（6×4.5 / 6×6 / 6×7 / 6×9） |
| **光源** | 任意手动闪光灯（参考配置：NEEWER TT560 + ZENIKO T1 引闪器） |
| **壳体** | 一体打印主箱 + 裙边顶盖 + 插塞式抽口盖板 |

| **胶片台** | 三点调平，200 × 230 mm，开口 100 × 120 mm |

| **装配时间** | 约 15 分钟，无胶粘结构件 |

## 为什么是这个形状

整套设计由三条约束推导而来。

**灯躺下了，所以箱子矮。** 传统光源箱里闪光灯是立着的，向上穿过一叠扩散板，箱体必须容纳灯头高度**加上**一段很长的混光距离，通常要 300 mm 以上。这里闪光灯平躺、横向出光，混光发生在箱体长度方向上——而这段长度本来就被灯身占着。于是高度塌缩为 `灯厚 + 41 mm`。

**全白内腔就是混光器。** 没有反射斜板、没有挡板、没有任何内部可调件。白色 PLA 壁面靠多次漫反射完成混光，亚克力只负责最后的平滑。这一点是按作者既有工作方式验证的：单层亚克力贴近胶片摆放，已经能得到满意的均匀度。

**任何东西都不接触影像区。** 胶片落在 0.3 mm 高的滑槽里，只有非影像区的片边被承托，影像区上下各留 0.2 mm 悬空，防刮擦也防牛顿环。换幅靠把胶片沿滑槽横向抽动完成——整卷拍完都不用开夹。

## 快速开始

1. **打印** —— 8 个 STL，分两种颜色（另有 2 个可选件）。参数见 [docs/printing.md](docs/printing.md)；主箱需要至少 280 × 300 mm 的打印床。
2. **采购** —— 一块 110 × 130 × 2 mm 乳白亚克力、3 根 M6×35 全牙螺杆配 6 颗螺母、3 颗 M6 热熔铜螺母。完整清单见 [docs/bom.md](docs/bom.md)（含淘宝下单话术）。
3. **装配** —— 烫入 3 颗铜螺母、外表面喷哑光黑、把胶片台架到螺杆上、闪光灯丢进箱底。分步说明见 [docs/assembly.md](docs/assembly.md)。
4. **校准** —— 拍摄无胶片的发光面，做 flat-field 校正后确认四角落差在 ±0.1 EV 左右。

## 换用其他闪光灯

参考配置是 NEEWER TT560（190 × 75 × 55 mm）配 ZENIKO T1 接收器（39 × 38 × 29.5 mm）。换成任何其他手动闪光灯时，按平躺状态实测尺寸重新推导箱体：

```
高 = 灯厚 + 41 mm
深 = 灯长 + 接收器长度 + 53 mm
宽 = 208 mm （固定：内腔 202 mm + 2 × 3 mm 壁厚）
```

宽度由发光窗口及其四周的白壁余量决定，与闪光灯无关，因此不变。顶盖以上的一切——胶片台、扩散板、胶片夹——则与闪光灯完全无关。完整尺寸链见 [docs/design.md](docs/design.md)。

## 当前状态

原型阶段。几何尺寸已在 Blender 源文件中逐项验证、配合间隙也做过数值核对，但实物尚未拍摄和做均匀度测试。第一次校准时预计会暴露两件事：灯身上表面是否需要贴白纸，以及扩散板中心是否需要贴减光点。
